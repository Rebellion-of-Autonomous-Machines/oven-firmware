# RS-485 / Modbus (дверь)

Параметры slave:
- UART: `Serial2`
- RXD: `GPIO14`
- TXD: `GPIO27`
- Скорость: `9600 8N1`
- Slave ID: `1`

## Holding registers

- `0` `RW` `COMMAND`  
  После обработки команда сбрасывается прошивкой в `0`.
- `1` `RO` `DIRECTION`  
  `0` = stop, `1` = open, `2` = close
- `2` `RO` `STATUS_BITS`  
  bit0 = door moving  
  bit1 = door open  
  bit2 = door closed  
  bit3 = web/Modbus commands enabled  
  bit4 = manual open selected (`DI5=1`, `DI6=1`)  
  bit5 = manual close selected (`DI5=0`, `DI6=1`)  
  bit6 = invalid input combination or input read error  
  bit7 = manual command armed, waiting for return to automatic
- `3` `RO` `COMMAND_RESULT`  
  `0` = ok, `1` = unknown command, `2` = busy

## Команды (`reg 0`)

- `1` открыть дверь
- `2` закрыть дверь

Во время 6-секундного хода повторные и противоположные команды отклоняются с результатом `busy`. После завершения хода оба моторных реле выключаются, и становится доступна только команда движения в противоположную сторону.

## Режимы DI5/DI6

- `1/0` — автоматический режим, веб и Modbus разрешены.
- `1/1` — ручное открытие, веб и Modbus заблокированы.
- `0/1` — ручное закрытие, веб и Modbus заблокированы.
- `0/0` — недопустимое состояние, веб и Modbus заблокированы.

Для ручного управления сначала переведите ключ в `Открыть` или `Закрыть`, затем верните его в `Автомат`. Только возврат в автоматическое положение запускает выбранное движение.

Состояния DI5/DI6 фильтруются в течение 80 мс. Комбинация закрытия `0/1` после этого фиксируется сразу, имеет приоритет и заменяет ранее ожидавшее открытие. Комбинация открытия `1/1` должна оставаться неизменной ещё 350 мс, поскольку она может кратковременно возникать при движении ключа к положению `Закрыть`. После фиксации закрытия переходное `1/1` при возврате ключа в `Автомат` не может изменить направление обратно на открытие.

Во время движения все команды от ключа, веб-интерфейса и Modbus игнорируются. Команды не ставятся в очередь. Если ключ переключался во время движения, после завершения его нужно вернуть в `Автомат`, а затем повторить полную последовательность ручной команды.

После включения контроллер сначала должен увидеть ключ в положении `Автомат`. Если питание включено при положении `Открыть` или `Закрыть`, это положение не принимается как ручная команда, а удалённое управление остаётся заблокированным до возврата ключа в `Автомат`.

При каждом включении контроллер выполняет обязательный 6-секундный цикл закрытия. Во время стартового закрытия все команды блокируются. После завершения дверь считается закрытой: повторные команды закрытия не включают реле, принять можно только команду открытия.

## Тестер

Файл: `tools/rs485_door_tester.py`

Установка зависимостей:

pip install pymodbus pyserial

python tools/rs485_door_tester.py
